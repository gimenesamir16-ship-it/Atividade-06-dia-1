# SmartStock – Arquitetura da Solução

Fluxo principal:
Usuário → Front-end Web (React) → API REST (Node.js, autenticação JWT) → Banco de Dados (PostgreSQL)

Integrações futuras (Dia 9):
- Agente de IA conectado à API, para consultas em linguagem natural e sugestões de reposição.
- N8N para automações: alertas de reposição por e-mail e painel, relatórios agendados.
